# Exam requirements (Basics of Information Systems, fall 2026-2027)

Format: offline project presentation, English, 180 min.

## Presentation (15 pts) — slides must contain
1. Project topic 2. Aim 3. Objectives (3-5+) 4. Competitive analysis (2-3 competitors) 5. SWOT 6. Use-case diagram (3+ actors, 5+ use cases) 7. ER diagram (5+ entities with PK and FK)

## Demo (working project)
- More than 5 functionalities — 10 pts
- Multilanguage (2+ languages, correct switching, consistent UI translation) — 5 pts
- Search (accurate, 2-3 entity types, clean UI) — 5 pts
- Admin panel (CRUD, role-based access, organized layout) — 5 pts
